Frequently Asked Questions

Getting started

1. Install prerequisites

Go to the Setup tab and install Rojo, the Roblox Studio Plugin, and the MCP Server.

2. Create a project

Go to Projects, click + New, choose a name and folder. The app creates a Rojo project with src/ directories and a CLAUDE.md context file.

3. Start developing

  1. Select your project from the sidebar
  2. Click Start Rojo to enable live sync with Studio
  3. Click Open Claude Code to start building with AI
What is Rojo?

Rojo syncs Lua/Luau files from your filesystem into Roblox Studio in real-time. Instead of editing scripts inside Studio, you edit them in your preferred editor (or via Claude Code), and Rojo pushes changes automatically.

Install: cargo install rojo or download from rojo.space

Project structure

Each project is a standard Rojo layout:

src/
  ServerScriptService/
  ReplicatedStorage/
  StarterPlayer/
default.project.json
CLAUDE.md

Edit Lua scripts inside src/. Rojo syncs them to Roblox Studio. CLAUDE.md gives Claude Code context about your project.

How does Claude Code control Roblox Studio?

Via the MCP Server (Model Context Protocol). Once installed from the Setup tab, Claude Code can:

  • Create and modify scripts in Studio
  • Insert models and instances
  • Run code inside Studio
  • Control play mode
  • Read the project structure
